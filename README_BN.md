# Savar Club of Football — Live Player Auction (ফ্রি সেটআপ)

এই প্যাকেজে আছে:
- `public/index.html` — নেভি/লাল Player Auction পেজ, ক্লাবের লোগো ও ব্যাকগ্রাউন্ডসহ
- `firestore.rules` — দর্শক/অ্যাডমিন/অধিনায়কের জন্য ডেটাবেস নিরাপত্তা নিয়ম
- `firebase.json` — Firebase Hosting কনফিগ

## কী কী কাজ করবে
- দর্শক লগইন ছাড়াই লাইভ দল, খেলোয়াড়ের ছবি, বেস প্রাইস এবং বর্তমান সর্বোচ্চ দর দেখতে পারবেন।
- অধিনায়ক নিজের অ্যাকাউন্টে লগইন করে শুধু তার নির্ধারিত দলের হয়ে দর দিতে পারবেন। অন্য দলের হয়ে বিড করতে পারবেন না।
- প্রথম দর বেস প্রাইস; পরবর্তী প্রতিটি বিডে ৳৫,০০০ যোগ হবে। একই দল একই খেলোয়াড়ে নিজের সর্বোচ্চ দর অতিক্রম করতে পারবে না।
- অ্যাডমিন দল, বাজেট, খেলোয়াড়, ছবি, সময়কাল ও দলের সীমা ১–১০ নিয়ন্ত্রণ করবেন।
- নিলাম শেষ হলে প্রতিটি দলের কেনা খেলোয়াড়, বিক্রয়মূল্য, মোট খরচ, অবিক্রিত খেলোয়াড় এবং CSV ফলাফল দেখা যাবে।
- ছবিগুলো ছোট JPEG-এ কমপ্রেস করে Firestore-এ রাখা হয়। বড় ছবি হলে ছোট ছবি বেছে নিতে হবে।

## ধাপ ১ — Firebase প্রজেক্ট তৈরি (ফ্রি)
1. https://console.firebase.google.com/ খুলে Google Account দিয়ে লগইন করো।
2. **Add project** দিয়ে `Savar Live Auction` নামে প্রজেক্ট বানাও। শুরুতে Google Analytics বন্ধ রাখতে পারো। Spark / no-cost plan ব্যবহার করো।
3. প্রজেক্টের **Project settings → General → Your apps → Web app (</>)** থেকে একটি Web app রেজিস্টার করো। Firebase config দেখাবে।
4. `public/index.html` ফাইলে `const firebaseConfig = { ... }` অংশে Firebase থেকে পাওয়া `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId` বসাও। `YOUR_...` placeholder রেখে দিলে অ্যাপ চালু হবে না। Firebase web config সাধারণত ক্লায়েন্টে থাকে; আসল নিরাপত্তা Firestore Rules দিয়ে নিয়ন্ত্রিত হয়।
5. **Authentication → Sign-in method** থেকে **Email/Password** চালু করো।
6. **Firestore Database → Create database** থেকে একটি database তৈরি করো। নিকটবর্তী region বেছে নাও; region পরে বদলানো কঠিন।
7. **Firestore Database → Rules**-এ এই প্যাকেজের `firestore.rules` ফাইলের সম্পূর্ণ কনটেন্ট পেস্ট করে **Publish** করো। Rules প্রকাশ না করা পর্যন্ত লাইভ ডেটা read/write কাজ করবে না।

## ধাপ ২ — ফ্রিতে সাইট লাইভ করো (Firebase Hosting)
এই ফোল্ডারের ভেতর terminal/Command Prompt খোলো (যে ফোল্ডারে `firebase.json` আছে), তারপর:

```bash
npm install -g firebase-tools
firebase login
firebase use --add
firebase deploy --only hosting,firestore:rules
```

`firebase use --add`-এ ধাপ ১-এ বানানো প্রজেক্ট বেছে নাও। Deploy শেষে Firebase একটি `https://...web.app` লিংক দেবে—সেটাই সবাইকে শেয়ার করবে। Node.js আগে ইনস্টল না থাকলে https://nodejs.org/ থেকে LTS ইনস্টল করো।

## ধাপ ৩ — প্রথম অ্যাডমিন সেট করো (গুরুত্বপূর্ণ)
1. লাইভ সাইট খুলে **নতুন অ্যাকাউন্ট** দিয়ে নিজের ইমেইল/পাসওয়ার্ডে একবার রেজিস্টার করো।
2. লগইন বক্সের নিচে দেখানো **UID** কপি করো।
3. Firebase Console → Firestore Database → Data → **Start collection**: collection ID `users`। Document ID হিসেবে নিজের UID হুবহু পেস্ট করো। Field: `role` (string) = `admin`। আর কোনো field লাগবে না।
4. পেজ রিফ্রেশ করো। এখন অ্যাডমিন প্যানেল দেখতে পাবে। এই প্রথম admin document শুধু Firebase Console-এ তৈরি করতে হয়, কারণ অন্য কাউকে নিজে admin হওয়া থেকে Rules আটকায়।

## ধাপ ৪ — অধিনায়কদের অ্যাক্সেস দাও
1. অধিনায়করা একই লাইভ URL-এ গিয়ে **নতুন অ্যাকাউন্ট** তৈরি করবে।
2. তাদের লগইন হওয়ার পর যে UID দেখায়, সেটি তোমাকে পাঠাবে। পাসওয়ার্ড কাউকে পাঠাতে হবে না।
3. অ্যাডমিন প্যানেলে আগে দল তৈরি করো, তারপর **অধিনায়ককে দলের অ্যাক্সেস দিন** অংশে অধিনায়কের UID ও দল বেছে নাও।
4. অধিনায়ক পেজ রিফ্রেশ/আবার লগইন করলে নিজের দলের হয়ে বিড করতে পারবে। অন্য দলের হয়ে বিড করার অনুমতি নেই।

## ধাপ ৫ — নিলাম পরিচালনা
1. দল যোগ করার সময় বাজেট ও ঐচ্ছিক লোগো দাও।
2. খেলোয়াড় যোগ করার সময় নাম, পজিশন, বেস প্রাইস ও ঐচ্ছিক ছবি দাও।
3. সর্বোচ্চ দল ১–১০ বেছে সময়কাল সেট করে **নিলাম শুরু** চাপো।
4. অধিনায়করা দর দেবে; দর্শকদের পেজ স্বয়ংক্রিয়ভাবে লাইভ আপডেট হবে।
5. সময় শেষ হলে ফলাফল দেখা যাবে; অ্যাডমিন চাইলে **নিলাম শেষ** চাপতে পারে। CSV ডাউনলোড করা যাবে।

## গুরুত্বপূর্ণ নোট
- এটি একটি একক নিলামের প্রাথমিক, ফ্রি সংস্করণ। Firestore-এর no-cost quota ও hosting quota অতিক্রম করলে আপডেট থেমে যেতে পারে বা বিলিং-সম্পর্কিত ব্যবস্থা লাগতে পারে—Firebase usage dashboard নজরে রাখো।
- অধিনায়কের বিড নিরাপত্তা Firestore Rules দিয়ে যাচাই হয়: লগইন, নির্দিষ্ট দল, নিলাম লাইভ থাকা, এবং প্রতি বিডে ৳৫,০০০ বৃদ্ধি। বাজেটের সীমা পেজে যাচাই করা হয়; খুব একই সময়ে একই দলের একাধিক concurrent bid হলে বাজেট যাচাইটি সার্ভার-সাইড ফাইন্যান্সিয়াল লক নয়। এই free starter-এ একজন অধিনায়ক/দল ধরেই ব্যবহার করো।
- বড় ফাইল Firestore document limit ছুঁতে পারে; তাই কমপ্রেসড ছবি ব্যবহার করো।
- Admin UID ও captain UID ব্যবহার করো; কাউকে পাসওয়ার্ড দেবে না। Admin role কেবল নিজের বিশ্বস্ত অ্যাকাউন্টকে দেবে।
- এখনো Firebase Console-এ প্রজেক্ট বানানো/তোমার account-এ deploy করা হয়নি, কারণ সেটি তোমার Google login/প্রজেক্ট-অ্যাক্সেস ছাড়া করা যায় না। উপরের সেটআপ একবার সম্পন্ন করলেই সাইট অনলাইনে থাকবে।
